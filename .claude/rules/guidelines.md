## General
- Do not make decisions on architecture yourself, always prompt the user to decide.
- Never assume, always ask clarifying questions and/or research first yourself.
- Make sure to avoid re-inventing the wheel: always check if existing libraries/features can solve the problem at hand. Quality gates for suggestions are
  - github stars
  - how many people are actively maintaining the solution
  - is it an "official" repository
  - when was the last release and the last commit
- If you rewrite existing code, apply the current rules to it.
- If you touch code that violates our rules, fix it immediately.
